# 苔光远行 Mossbound

一款在浏览器里直接游玩的原创视觉平台冒险游戏。单个 HTML 文件包含游戏、画面和合成音乐，无需安装依赖。

[开始游戏](https://heliotrope-dev.github.io/platform-game/)

## 世界与角色

- 苔光原野、蓝晶回廊、赤砂熔谷，以及最终的星环遗迹。
- 巡林员、星航员、苔灵三种外观，共用相同的碰撞尺寸和动作参数。
- 新绘制的矿壳兽、晶翼、熔谷生物、星环守卫、地形与道具。
- 按角色区分的晶核子弹、敌方晶簇弹、Boss 环形冲击波与方向拖尾。
- 实时状态栏、关卡进度、强化倒计时、结算面板和当前浏览器的最高分记录。
- 每关探索目标与额外奖励。
- 三次关间能力选择：踏风、连发晶核、引光石、守护纹章，每项可升至两级。

## 操作

- 方向键左右或 A/D：移动。
- 上方向键或 W：跳跃；支持约 0.1 秒的边缘宽限与落地前输入缓冲。
- 空格：射击；Z：切换外观。
- P / Esc：暂停或继续；H：说明；M：静音；F：全屏。
- 失败或通关后 R：重开；逗号 / 句号：上一关 / 下一关。
- 手机使用屏幕下方触控按钮，支持同时移动与跳跃。

切换窗口会暂停。返回后点击继续，避免角色在后台受伤。声音开关与最高分存储在当前浏览器；浏览器禁止存储或不支持音频时仍可游玩。

## 保留的玩法

关卡生成、基础移动参数、基础跳跃高度、碰撞尺寸、初始生命值、敌人掉落沿用原版。额外能力通过通关后的选择获得，只在本局生效。基础跳跃增加短暂的起跳宽限与输入缓冲。物理固定以每秒 60 步运行，避免高刷新率屏幕加快游戏。

## 星环守卫 Boss 战

Boss 保持 100 点生命值，在 70、35 点进入下一阶段，弹幕由 3 发增加到 5 发、7 发。

- 晶簇扇射：沿预警方向发射，瞄准位置锁定后可移动闪避。
- 横扫：约 0.9 秒的横向预警后冲刺，可通过上下层平台躲避。
- 重砸：标记落点后下降，落地产生向两侧扩散的冲击波。
- 星落：后两个阶段增加定点光柱，预警至少约 0.78 秒，保留安全走位区域。
- 攻击后的恢复期暴露核心，子弹与踩头造成双倍伤害。其他时期不能踩头。
- 场地包含一块横向移动的中层平台。失败消耗机会后保留 Boss 生命值，清除正在进行的弹幕和光柱，留出重新准备的时间。

主要难度来自攻击组合、召唤压力和走位。接触普通敌人、Boss 或小兵均按生命值受伤，不再直接消耗整次机会。

## 本地运行与检查

直接打开 `mario_game.html`，或在本目录运行：

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

打开 `http://127.0.0.1:8765/`。

逻辑回归测试使用 Node 内置测试工具：

```sh
node --test tests/game.test.mjs
```

测试覆盖音频波形、四关启动与绘制、说明与暂停、刷新率一致性、跳跃缓冲、触控取消、关间能力选择、额外跳跃次数、连发、吸附、护盾、目标奖励及无音频/无存储环境。另覆盖普通接触伤害、能量保护与深坑、岩浆表面判定、粒子回收、复活状态清理、过关计分、Boss 击败后的胜利优先结算，以及说明页切出后的手动继续。浏览器内另外检查桌面与手机视图。测试不代表已人工完整通关全部随机种子。
